# Text-Summarization-using-LLM-with-ROUGE-Evaluation
Automated text summarization pipeline with NLP preprocessing and ROUGE-based evaluation for accuracy measurement.

This project focuses on building an automated text summarization system using NLP techniques and Large Language Models. It includes preprocessing using NLTK and evaluates summarization quality using ROUGE metrics such as ROUGE-1, ROUGE-2, and ROUGE-L.
# LLM-Based Text Summarization with Evaluation

## Overview
Implemented a text summarization pipeline with evaluation using ROUGE metrics.

## Features
- Text preprocessing using NLTK
- Summarization workflow
- Evaluation using ROUGE scores

## Tech Stack
- Python
- NLTK
- HuggingFace Evaluate

## Metrics Used
- ROUGE-1
- ROUGE-2
- ROUGE-L
